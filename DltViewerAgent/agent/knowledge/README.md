# Knowledge base

Copy reference material for the DLT Viewer agent here. Subfolders are fine.

- **Formats:** `.md` (best), `.txt`, `.csv`, `.json`, `.yaml`. Convert PDFs first, e.g. with `pdf_to_markdown_tool`.
- **Structure:** start each file with a `# Title`. Use `##` headings for topics, because the agent retrieves one heading section at a time.
- **Pick-up:** the agent sees a list of file titles and searches or reads files only when needed. New files appear in a **New chat**; edits to existing files apply immediately.
- **Content:** app/context ID meanings, ECU behaviour, known fault signatures, DTC notes, and analysis procedures.
- **Do not include** secrets or anything that may not be sent to GitHub Copilot. Retrieved text is sent to the model.

This README is not indexed.
