# Camera Inventory

## Scope

Use this document to resolve any camera abbreviation seen in DLT evidence to its physical position and naming pattern.

## Naming convention

| Prefix | Meaning |
| --- | --- |
| `FLCW` | Front Looking Centre Wide — single front-center wide-angle camera. |
| `SRC<x>` | Short Range Camera, `<x>` = position. |
| `LR<a><b>` | Long Range camera, `<a>` = mount group, `<b>` = side. |

Position letters used above:

| Letter | Meaning | Used in |
| --- | --- | --- |
| `F` | Front | `SRC` |
| `L` | Left | `SRC`, `LR` (second letter) |
| `R` | Right | `SRC`, `LR` (second letter) |
| `B` | Back | `SRC`, `LR` (first letter) |
| `I` | Intersection | `LR` (first letter) |

## Caveats

This document only defines naming. It does not describe per-camera behavior, failure modes, or physical mounting details — add those to dedicated documents as they are confirmed.
