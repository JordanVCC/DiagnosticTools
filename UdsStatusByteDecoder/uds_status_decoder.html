Standard UDS DTC Status Byte Decoder

Enter one or more status bytes and decode each bit according to ISO 14229 DTC status definitions.

Separators supported: spaces, commas, semicolons, tabs, and new lines. Bytes can be written as 2f or 0x2f.

Bit Decoded Bit Mask Standard Name Meaning When Set
Input Byte Binary Bit 7 Bit 6 Bit 5 Bit 4 Bit 3 Bit 2 Bit 1 Bit 0

Bit numbering follows the UDS convention where bit 0 is the least significant bit and bit 7 is the most significant bit.
